4.9.15 使用包名 com.hermes.mytv.cloud 和原正式证书，可直接覆盖 4.9.14 及更早的同包名版本。已有同包名云源版可直接覆盖安装，保留收藏及应用数据；请勿卸载旧版或清除数据。
